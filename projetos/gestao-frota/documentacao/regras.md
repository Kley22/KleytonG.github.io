# Regras e limites

Distância = hodômetro atual − anterior. Consumo = distância / litros, supondo abastecimentos consecutivos ao mesmo nível. Hodômetro atual deve superar o anterior; litros devem ser positivos. Distância até manutenção = hodômetro de manutenção − atual. Limite ilustrativo de aviso: 500 km. Zero ou negativo indica quilometragem atingida. Manutenção por data ainda não está incluída.

Todos os dados são fictícios. Alterações feitas no navegador não são gravadas. Entradas inválidas mantêm o último resultado válido, com aviso visível.
